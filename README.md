# Denice Portfolio

A personal portfolio website built with **Next.js** to showcase my projects, background, contact information, and professional work.
(Work in progress)

## 🌐 Live Site

This portfolio is deployed using **GitHub Pages**. https://99liner.github.io/my-page/

> The website is currently a work in progress.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Custom navigation header
- Home and About sections
- Project showcase
- In-page project navigation
- Contact page
- Social links
- Reusable global footer
- Static deployment through GitHub Pages

## 🛠️ Built With

- **Next.js**
- **React**
- **JavaScript**
- **CSS / CSS Modules**
- **Git**
- **GitHub Pages**
